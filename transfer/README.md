# Transfer

异步注册内存传输。TCP 是请求—响应实现，不具有 RDMA 单边语义。

- 每次注册生成随机 128 位标识，旧描述符不能命中重启后的新区域。
- `RemoteRegion` 通过 `to_string()` 和 `parse()` 跨进程交换，格式为 `endpoint/id`，支持 IPv6。
- `limit` 分别限制客户端在途请求、服务端连接和接收中的请求。服务端先取得许可，再分配 payload；关闭时等待连接任务退出。
- TCP 协议版本为 2，双方必须同步升级。

## 取消与超时

取消和超时不等于远端回滚。已经提交的操作先排空，完成通知之前保留本地资源；取消后的 Read 不再写入本地目标。

`timeout` 是执行期限，不是完成通知的硬上限。TCP 连接和响应等待各有两倍期限的保护，超限关闭连接；其他 Transport 必须自行保证最终完成或报告错误。

Write 若丢失回复，返回 `Error::Uncertain`，当前 Engine 拒绝继续使用该远端区域。调用方必须联系远端所有者，完成 `deregister` 后才能复用目标内存；其他客户端也必须遵守此隔离规则。无法确认远端状态时不得发布或重新使用该区域。

## 验证

GitHub CI 使用 `cargo test --workspace --all-features`。测试覆盖描述符往返、子进程重启后的旧标识拒绝、双进程 Read/Write、取消排空、写入结果不确定、连接限流与关闭。

`bench` 目前是同进程 loopback 微基准，不是双进程或跨机器性能结果。
